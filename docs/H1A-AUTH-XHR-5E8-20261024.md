El operador ahora registra un terminal `NETWORK_FINISHED` positivo únicamente si hay respuesta correlacionada y estado HTTP válido; el gate exige REQUEST, RESPONSE y TERMINAL para cada ordinal. Una cancelación, error de red, terminal sin respuesta, petición activa o evento desconocido sigue bloqueando. No se cambió el producto ni la política de origen.

## Automatización posible

Preparación de fichas, validación NAP, deduplicación, payloads y seguimiento: automatizables una vez implementados.

Envíos: API oficial y cuenta autorizada cuando exista acceso suficiente; interfaz asistida si el canal lo permite y el usuario autorizó ese destino. No prometer automatización universal ni asumir API de escritura por existir interfaz pública.

Verificaciones por teléfono, vídeo, identidad, códigos, CAPTCHA o aceptación de cuotas: intervención del propietario cuando el canal la exige. No eludir controles.

No altas masivas, reseñas inventadas ni compra de enlaces para manipular posiciones. Un trabajo programado puede revisar estados y preparar borradores; no concede por sí mismo permiso para publicar.
